# 《明日方舟》六星干员练度建议手册

该项目旨在为《明日方舟》的六星干员提供练度建议，包含各个干员的培养优先级、专精建议和模组建议。

## 使用说明
首页点击职业图标选择相应职业快捷查询。单击干员卡片可跳转至对应的PRTS页面。

## 管理后台
项目已支持通过网页表单维护干员资料。首次部署配置请阅读 [ADMIN_SETUP.md](ADMIN_SETUP.md)。配置完成后访问 `/admin/` 登录 GitHub，即可新增、编辑、删除干员，无需修改 HTML。
